📡 FTP Upload Methods
════════════════════════════════════════════════════════════════════════════════

Method 1: FileZilla (GUI)
   1. Download FileZilla
   2. File → Site Manager
   3. Add FTP server details
   4. Drag & drop files

Method 2: SFTP (CLI)
   sftp user@server.com
   sftp> put -r app
   sftp> put -r components
   ...

Method 3: Git Deploy
   1. Push to GitHub
   2. SSH to server
   3. git clone repo
   4. pnpm install
   5. pnpm build
   6. pm2 start...

📝 AFTER UPLOADING (Server Setup)
════════════════════════════════════════════════════════════════════════════════

1. SSH to server:
   ssh user@server.com

2. Navigate to app:
   cd ~/public_html/nextjs-app

3. Install Node.js (if needed):
   curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
   sudo apt install nodejs

4. Install pnpm:
   npm install -g pnpm

5. Install dependencies:
   pnpm install

6. Setup environment:
   nano .env.production
   # Add: NEXT_PUBLIC_API_URL=...

7. Build app:
   pnpm build

8. Run with PM2:
   npm install -g pm2
   pm2 start "pnpm start" --name "nextjs"
   pm2 startup
   pm2 save

9. Setup Nginx (reverse proxy):
   sudo apt install nginx
   # Configure nginx.conf for localhost:3000

10. Setup SSL (free with Let's Encrypt):
    sudo apt install certbot
    sudo certbot certonly -d yourdomain.com
